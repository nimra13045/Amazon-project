# 🛒 Amazon Clone Project

This is an **Amazon Clone website** built using **HTML, CSS, and JavaScript**.  
The project is created for learning and practicing front-end development skills by replicating a real e-commerce website UI.

---

## 📌 Technologies Used
- HTML5  
- CSS3  
- JavaScript  

---

## 🎯 Features
- Amazon-like homepage design  
- Navigation bar with search box  
- Product category sections  
- Image sliders / banners  
- Product cards layout  
- Hover effects and interactive UI design  

---

## ⚠️ Important Note
This project is **not fully responsive**.  
It is designed for desktop view only and made for learning purposes.
